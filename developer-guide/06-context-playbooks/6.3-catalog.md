# 6.3 Catalog — playbook

How to implement the Catalog context. The largest non-integration context — it owns the entire product model, pricing computation, multi-catalog projection, and the platform-defined category taxonomy. Everything that becomes a Beckn `Resource` originates here.

> **Read first**: [handoff §4.3 Catalog](../../handoff/04-bounded-contexts/4.3-catalog.md), [`design/catalog.md`](../../design/catalog.md), [ADR-0004](../../decisions/0004-store-publication-and-multi-catalog-projection.md), [ADR-0005](../../decisions/0005-catalog-and-product-modeling.md), [ADR-0007](../../decisions/0007-pricing-tax-and-vouchers.md), [ADR-0008](../../decisions/0008-localization-and-localizedtext.md), [ADR-0020](../../decisions/0020-default-catalog-mandatory.md).

## At a glance

| Aspect | Detail |
|---|---|
| Phase landed | [Phase 3](../05-phases.md) — Catalog |
| Owns | `Product` (Matrix / Flat), `ProductVariant`, `ProductAttribute`, `Catalog` (Default + additional), `CatalogMembership`, `PlatformCategory`, `ProductCategoryAssignment`, `Media` |
| External systems | Object storage (signed-URL provider — D4) |
| Cross-context users | Inventory (anchors `StockLevel` to Product / Variant), Promotion (vouchers apply to Catalog prices), Order (Quote snapshots), Bridge (Beckn projection) |

## Entities

### `Product`

| Field | Notes |
|---|---|
| `id`, `store_id` | `store_id` is cross-context ref to Tenancy |
| `mode` | `'matrix' \| 'flat'`; **immutable** after creation |
| `name` | `LocalizedText`; unique within store (default-locale check) |
| `description` | `LocalizedText` |
| `sku` | optional; unique within store if set |
| `status` | `'draft' \| 'active' \| 'archived'` |
| `base_price` | `Money`; required for Active |
| `tax_rate` | `TaxRate` (decimal pct); required for Active |
| `tax_amount` | Derived: `round(base_price × tax_rate / 100)`; cached |
| `published_price` | Derived: `base_price + tax_amount`; cached |
| Timestamps | created_at, updated_at |

**Invariants:**
- `mode` is immutable.
- `Store.currency` is locked once any `status='active'` Product exists in the store.
- `name.entries.id` must be set (LocalizedText invariant).
- Active requires: `base_price`, `tax_rate`, ≥1 `ProductCategoryAssignment` to a non-deprecated PlatformCategory.

**Lifecycle:** `Draft` → `Active` → `Archived`. `Active → Draft` forbidden. `Archived → Active` allowed if invariants still hold. No deletion.

### `ProductVariant` (Matrix mode only)

| Field | Notes |
|---|---|
| `id`, `product_id` | |
| `attribute_values` | One per parent's `ProductAttribute` (e.g., `{Size: 'L', Color: 'red'}`) |
| `price_override` | Optional `Money`; if absent, inherits parent's `base_price` |
| `media` | Optional override list; inherits parent's if absent |
| `tax_rate` | NOT per-variant; **always inherits parent's** (no per-variant tax) |

### `ProductAttribute` (Matrix mode)

`name: LocalizedText`, `allowed_values: Array<{ id, label?: LocalizedText }>`. Value identity (`id`) is locale-neutral.

### `Catalog`

| Field | Notes |
|---|---|
| `id`, `store_id` | |
| `name` | `LocalizedText` (Default Catalog: name auto-derived from store name; not user-editable) |
| `is_default` | boolean; exactly one per store; non-deletable |
| `created_at` | |

### `CatalogMembership` (additional Catalogs only)

`(catalog_id, product_id)`. Default Catalog membership is **implicit** per [ADR-0020](../../decisions/0020-default-catalog-mandatory.md) — no row needed.

### `PlatformCategory`

Hierarchical (tree). `id`, `parent_id` (nullable), `name: LocalizedText`, `status` (`'active' \| 'deprecated'`). Cannot be deleted if any `ProductCategoryAssignment` references it.

### `Media`

`{ id, product_id, variant_id?, position, storage_ref, alt_text: LocalizedText }`. `storage_ref` is opaque (the object-store key). Domain knows only references.

| `CatalogProjectionReadPort` | Bridge | Full per-store catalog projection for CDS publishing |

## Use cases

### Product authoring (Store Admin)

| # | Use case | Capability | Notes |
|---|---|---|---|
| 1 | `CreateProduct` | `product.create` | Creates in `Draft`; sets `mode` (immutable); auto-implicit-included in Default Catalog. |
| 2 | `UpdateProduct` | `product.update` | Cannot change `mode`. Editing `base_price` / `tax_rate` triggers `pricing-calculator` recomputation. |
| 3 | `PublishProduct` | `product.publish` | `Draft → Active`. Validates invariants. |
| 4 | `ArchiveProduct` | `product.archive` | `Active → Archived`. Hides from network. |
| 5 | `RestoreProduct` | `product.restore` | `Archived → Active`. Re-validates invariants (categories non-deprecated). |
| 6 | `UpdateProductMedia` | `product.update` | Reorder / add / remove media references. Storage uploads happen pre-call via signed URLs. |

| # | Use case | Capability | Notes |
|---|---|---|---|
| 19 | `CreateCatalog` | `catalog.create` | Additional catalog (not Default — Default auto-created). |

| 22 | `IncludeProductInCatalog` | `catalog.update` | Additional Catalogs only. |

### Use case envelope highlights

- **`CreateProduct` requires a side effect**: implicit membership in Default Catalog. Don't write a `CatalogMembership` row for Default — the implicit rule is enforced at read time (Default-Catalog reads include all store products by definition).
- **`PublishProduct` triggers pricing recomputation** if any of `base_price`, `tax_rate` changed since creation. Pricing calculator lives in `domain/services/`.
- **`Archive` is the way to "remove" a product from Beckn**. There's no "exclude from Default Catalog" use case ([ADR-0020](../../decisions/0020-default-catalog-mandatory.md)).
- **PlatformCategory `Deprecate` doesn't delete**. Existing assignments stay valid; new assignments to a Deprecated category are rejected.

## Events emitted

(All `business_state` category unless noted — drives Audit retention ~2 years.)

Product lifecycle: `catalog.product_created`, `_updated`, `_published`, `_archived`, `_restored`, `_media_updated`.

Variant (Matrix): `catalog.product_variant_attribute_added`, `_variant_added`, `_variant_updated`, `_variant_removed`, `_variant_media_updated`.

Categorization: `catalog.product_category_assigned`, `_unassigned`.

Platform categories: `catalog.platform_category_created`, `_renamed`, `_moved`, `_deprecated`.

Store catalogs: `catalog.store_catalog_created`, `_renamed`, `_deleted`. Plus `catalog.product_included_in_catalog`, `_removed_from_catalog` (additional Catalogs only).

**Bridge subscribes to all of these for republication.** Inventory subscribes to product/variant create / archive / restore / variant-add / variant-remove for StockLevel auto-management.

| Event | Handler | Purpose |
|---|---|---|
| `tenancy.store_created` | `on-store-created.ts` | Auto-create the Default Catalog for the new Store. **Idempotent** — replay must not create duplicates. |

## Migration sketch

`migrations/0004__catalog.sql` (abbreviated):

```sql
CREATE TYPE product_mode AS ENUM ('matrix', 'flat');
CREATE TYPE product_status AS ENUM ('draft', 'active', 'archived');
CREATE TYPE platform_category_status AS ENUM ('active', 'deprecated');

CREATE TABLE platform_categories (
  id text PRIMARY KEY,
  parent_id text REFERENCES platform_categories(id),
  name jsonb NOT NULL,
  status platform_category_status NOT NULL DEFAULT 'active',
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE products (
  id text PRIMARY KEY,
  store_id text NOT NULL,                       -- cross-context ref
  mode product_mode NOT NULL,
  name jsonb NOT NULL,
  description jsonb NOT NULL,
  sku text,
  status product_status NOT NULL DEFAULT 'draft',
  base_price_amount bigint,                     -- Money minor units
  base_price_currency text,                     -- Money currency
  tax_rate numeric(5,2),
  tax_amount bigint,                            -- derived; cached
  published_price bigint,                       -- derived; cached
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX idx_products_store_name_default_locale
  ON products (store_id, (name->>'id'));
CREATE UNIQUE INDEX idx_products_store_sku
  ON products (store_id, sku) WHERE sku IS NOT NULL;

CREATE TABLE product_attributes (
  id text PRIMARY KEY,
  product_id text NOT NULL REFERENCES products(id),
  name jsonb NOT NULL,
  allowed_values jsonb NOT NULL,                -- array of { id, label? }
  display_order int NOT NULL
);

CREATE TABLE product_variants (
  id text PRIMARY KEY,
  product_id text NOT NULL REFERENCES products(id),
  attribute_values jsonb NOT NULL,              -- { attribute_id: value_id }
  price_override_amount bigint,                 -- nullable; inherits parent if null
  price_override_currency text,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE catalogs (
  id text PRIMARY KEY,
  store_id text NOT NULL,                       -- cross-context ref
  name jsonb NOT NULL,
  is_default boolean NOT NULL DEFAULT false,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX idx_catalogs_store_default
  ON catalogs (store_id) WHERE is_default = true;

CREATE TABLE catalog_memberships (
  catalog_id text NOT NULL REFERENCES catalogs(id),
  product_id text NOT NULL REFERENCES products(id),
  added_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (catalog_id, product_id)
);
-- NOTE: rows here only for additional Catalogs. Default Catalog membership is implicit.

CREATE TABLE product_category_assignments (
  product_id text NOT NULL REFERENCES products(id),
  platform_category_id text NOT NULL REFERENCES platform_categories(id),
  assigned_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (product_id, platform_category_id)
);

CREATE TABLE media (
  id text PRIMARY KEY,
  product_id text NOT NULL REFERENCES products(id),
  variant_id text REFERENCES product_variants(id),  -- nullable; product-level if null
  position int NOT NULL,
  storage_ref text NOT NULL,
  alt_text jsonb NOT NULL
);
```

## Cross-context integration

| Direction | Detail |
|---|---|
| **Provides** | `CatalogReadPort` (Order — Quote snapshots); `PlatformCategoryReadPort`, `CatalogProjectionReadPort` (Bridge — CDS publish + responses) |
| **Consumes** | `AuthorizationPort` (Tenancy); `TenancyStorePort` (Store currency / supported_locales); `ObjectStoragePort` (platform-infra) |

| **Subscribes to** | `tenancy.store_created` (Default Catalog auto-creation) |

## Implementation order (within this context)

1. **`PlatformCategory`** + repository + System Admin use cases. Stores need at least one PlatformCategory before they can Publish products.
2. **`Product`** entity (Matrix + Flat mode discriminator) + `ProductRepository` + `CreateProduct` + `UpdateProduct`.
3. **`PricingCalculator`** (`domain/services/`) + derived-field recomputation in `UpdateProduct`.
4. **`ProductCategoryAssignment`** + assign/unassign use cases.
5. **`PublishProduct`** + `ArchiveProduct` + `RestoreProduct` with invariant checks.
6. **Variants** (Matrix only): `ProductAttribute` + `ProductVariant` + all variant use cases.
7. **`Media`** + object-storage adapter (signed-URL flow) + media use cases.
8. **`Catalog`** entity + `CatalogRepository`.
9. **`on-store-created`** subscriber → auto-create Default Catalog.
10. **Additional Catalogs**: `CreateCatalog`, `RenameCatalog`, `DeleteCatalog`, `IncludeProductInCatalog`, `RemoveProductFromCatalog`.
11. **`CatalogReadPort` adapter** for Order (`getCapturableSnapshot(productId | variantId)`).
12. **`PlatformCategoryReadPort` adapter** + **`CatalogProjectionReadPort` adapter** for Bridge.

## Test checklist

**Domain tests**:
- [ ] `Product` invariants (mode immutability throws on mutation attempt).
- [ ] `Product` state transitions (Draft → Active rejects when invariants unmet; Active → Draft forbidden).
- [ ] `PricingCalculator` correctness (rounding semantics; multiple tax rates).
- [ ] `LocalizedText` invariant — Product names without `id` key throw.
- [ ] `Catalog` invariants (Default is_default flag).
- [ ] `PlatformCategory` hierarchical operations (move respecting tree validity).

**Application tests**:
- [ ] `CreateProduct` emits `product_created`; Default Catalog implicit-membership is observable via `CatalogReadPort` (no `CatalogMembership` row).
- [ ] `UpdateProduct` price change → recomputed `tax_amount` + `published_price`.
- [ ] `PublishProduct` rejected when no PlatformCategory assigned.
- [ ] `PublishProduct` rejected when assigned category is `Deprecated`.
- [ ] Currency lock — second `PublishProduct` in a different currency raises typed error.
- [ ] Two stores' products are isolated (one store's `CreateProduct` doesn't surface in another's reads).
- [ ] `RemoveProductFromCatalog` rejected when target catalog is Default.
- [ ] `on-store-created` subscriber is idempotent.
- [ ] Matrix mode: `AddProductVariant` rejected if attribute values incomplete.
- [ ] Flat mode: variant use cases reject the call (wrong mode).

**Infrastructure tests**:
- [ ] Round-trip every entity through its repository.
- [ ] `idx_products_store_name_default_locale` unique constraint catches duplicate names at the default-locale value.
- [ ] `idx_catalogs_store_default` enforces single Default Catalog per store.

## Gotchas

- **`Product.mode` is immutable.** Authoring UI must force the choice upfront. To "change a Matrix Product into Flat products," archive and recreate.
- **`Store.currency` locks** once the store has any Active product. Surface this in Store settings.
- **Default Catalog membership is implicit** ([ADR-0020](../../decisions/0020-default-catalog-mandatory.md)). Never write a `CatalogMembership` row for Default; never offer a "remove from Default" UI. Hiding = `ArchiveProduct`.
- **`Product.name` uniqueness checks against the default-locale value** (`name->>'id'`). Don't try to enforce cross-locale uniqueness.
- **Variants inherit parent's `tax_rate`.** No per-variant tax in v1.
- **PlatformCategory taxonomy is system-defined.** Stores assign their products to platform categories; they cannot create new categories. Store-private organization is via additional Catalogs.
- **At least one PlatformCategory assignment is required for Active products.** Surface this in the publish flow.
- **Media storage is Infrastructure.** Domain holds only `storage_ref` opaque references. Signed-URL upload happens before the use case — the use case records the reference.
- **Don't denormalize Store data into Product.** Store info comes from `TenancyStorePort` at read time.
- **`PublishProduct` is the trigger for Beckn republication** (via the `product_published` event). Bridge subscribes — the domain doesn't care how the network sees the change.
- **`Deprecate` ≠ `Delete` for PlatformCategory.** Deprecated categories remain referenceable for legacy assignments; new assignments are rejected. Deletion only when no assignments reference.
- **The pricing recomputation is in the domain, not the DB.** Don't put `tax_amount` as a computed column — the language for "round half-even" matters; keep it in `PricingCalculator`.
